Found a bug, want a new tool, or have a question? Here's how to reach the project.

Report a bug or request a feature

The fastest way is to open an issue on GitHub — it's public and tracked:

Open a GitHub issue →

Email

Prefer email? Write to contact@meldpdf.com. Please don't attach sensitive documents — meldpdf never needs your files, since every tool runs in your own browser.

A note on your files

meldpdf can't see your documents and doesn't want to. If a tool isn't working, describe what you did and what happened (and, if you can, the kind of PDF), rather than sending the file itself. See how your files are handled.
