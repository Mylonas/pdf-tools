PDF to Word — free and private

Get the text out of a PDF and into an editable Word document. It runs in your browser, so there's no upload, no sign-up and no watermark.

How to convert a PDF to Word

  1. Open the PDF → Word tool and add your PDF.
  2. Convert. The text is extracted and packaged as a .doc file.
  3. Download and open it in Microsoft Word, Google Docs or LibreOffice, then edit freely.

What this tool does — and doesn't

Fully accurate PDF-to-Word conversion that rebuilds every column, table and image is a heavy, server-side job. meldpdf takes a different, privacy-first approach: it pulls out the text so you can edit it, without ever sending your file anywhere. For letters, reports and mostly-text documents, that's exactly what people need. If you rely on the original visual layout being reproduced pixel-for-pixel, a desktop office suite is a better fit.

Converting a scanned PDF

If your PDF is a scan (a picture of a page), there's no text to extract and you'll get a blank document. Run it through OCR first to generate the text, then convert.

Frequently asked questions

Is my PDF uploaded?

No — the text is extracted and the Word file built in your browser. See our privacy policy.

Will the layout be preserved exactly?

The text is kept and made editable; complex layouts, columns and images are not reproduced.

I got a blank document — why?

Your PDF is scanned. Run OCR first, then convert.

Can I convert a password-protected PDF?

If the PDF requires a password to open, you'll need to remove the protection first. If it only restricts printing or copying but opens without a password, the tool can usually extract the text.

Which Word format does it produce?

The output is a .doc file that opens in Microsoft Word, Google Docs, LibreOffice Writer and most other word processors. It contains the extracted text as editable paragraphs.

When PDF to Word works well

This tool is at its best with text-heavy documents — the kind of files where the words are the point and the layout is secondary. Letters, memos, reports, essays, articles and contracts all convert cleanly. If you need to edit a paragraph, fix a typo or reuse a section of text, PDF to Word gives you an editable document in seconds.

It also works well for extracting content from forms and applications where the text is stored as real characters rather than scanned images. Government forms, insurance documents and financial statements that were generated digitally usually contain extractable text.

Limitations of browser-based conversion

Because the conversion runs entirely in your browser without a server, there are trade-offs compared to heavyweight desktop tools:

  • Layout is not preserved. Multi-column layouts, headers, footers, page numbers and text boxes are flattened into a simple text flow. You get the words in reading order, not the visual arrangement.
  • Tables lose their structure. Table content is extracted as text, but the rows and columns are not recreated in the Word document. You may need to rebuild the table manually.
  • Images are not included. Photographs, logos and graphics embedded in the PDF do not appear in the Word file. The tool focuses on text extraction.
  • Fonts may differ. The Word document uses your system's default fonts, not the fonts embedded in the PDF.

For most people who just need to grab the text and edit it, these trade-offs are perfectly acceptable. The benefit is that your file stays private and the conversion is instant.

Alternatives for complex documents

If you need a Word file that faithfully reproduces the original PDF's layout — columns, images, tables and all — a browser-based tool isn't the right fit. Here are better options for those cases:

  • Adobe Acrobat offers the most accurate PDF-to-Word conversion, preserving tables, images and formatting. It requires a paid subscription.
  • Google Docs can open a PDF and attempt to convert it. Upload the PDF to Google Drive, right-click it and choose "Open with Google Docs." The results vary but it handles simple layouts reasonably well.
  • LibreOffice Draw can open PDFs and preserve some layout elements. It's free and works offline.
  • Microsoft Word itself can open PDFs directly (File > Open) and does a decent job with moderately complex layouts.

Tips for the best result

  • Start with a digital PDF. Documents created from Word, Google Docs or any application produce clean text. Scanned documents need OCR first.
  • Check the output. Skim the Word file to make sure paragraphs are in the right order and nothing was missed.
  • Use Extract text if you only need plain text. If you don't need a Word file specifically, Extract text gives you a lightweight .txt file instead.
  • Break large PDFs into sections. If you only need a few pages, use Split PDF first to isolate them, then convert.
