Password protect a PDF — privately

Add a password to a sensitive PDF, or remove one you already know. It uses strong 256-bit AES encryption and runs in your browser — your file is never uploaded.

How to add a password

  1. Open the Protect / Unlock tool and add your PDF.
  2. Choose “Add a password” and type the password you want.
  3. Apply. The engine encrypts the file on your device (it downloads once on first use).
  4. Download the protected PDF and store the password somewhere safe.

How to remove a password you know

Switch the action to “Remove a password”, enter the PDF's current password, and download an unlocked copy. This only works when you know the password.

Choosing a good password

256-bit AES is only as strong as the password behind it. Use a long, unique passphrase, and share it with the recipient through a separate channel (not in the same email as the PDF).

Frequently asked questions

Is my PDF uploaded?

No — encryption runs in your browser. The engine downloads once; your file never leaves your device. See our privacy policy.

Can you remove a password I don't know?

No. That would be cracking encryption, which we don't do. You need the current password.

How strong is it?

256-bit AES, the strongest standard PDF encryption.

How PDF encryption works

When you add a password with this tool, the PDF is encrypted using AES-256 (Advanced Encryption Standard with a 256-bit key). This is the strongest encryption level defined in the PDF specification and the same standard used by governments and financial institutions to protect classified data. The encryption scrambles the file's contents so that without the correct password, the data is unreadable — not just hidden, but mathematically inaccessible.

The PDF format actually supports two types of password: a user password (sometimes called the "open password") that prevents anyone from opening the file, and an owner password (sometimes called the "permissions password") that restricts actions like printing, copying text, or editing while still allowing the file to be opened. This tool sets a user password — the stronger of the two — which means the file cannot be opened at all without the correct password.

When to encrypt a PDF

Password protection is worth using whenever a PDF contains information you would not want a stranger to read. Common situations include:

  • Emailing sensitive documents — tax returns, contracts, medical records, ID copies. Email is not encrypted end-to-end by default, so a password adds a layer of protection in transit and at rest.
  • Sharing via cloud storage — if a shared link leaks or is guessed, the file is still locked.
  • Archiving personal records — protecting files on your own drive guards against someone accessing your computer or backup.
  • Client deliverables — sending a password-protected report to a client and sharing the password through a separate channel (a text message, a phone call) is standard practice in many industries.

Always share the password through a different channel than the PDF itself. Putting both in the same email defeats the purpose.

Limitations of PDF passwords

PDF encryption is strong, but it is worth understanding its boundaries:

  • A user password (the kind this tool sets) is genuinely secure. Without the password, the file's contents are encrypted and cannot be read. The strength depends entirely on the password you choose — a short or common password can be brute-forced, while a long, random passphrase is effectively unbreakable.
  • An owner password (permissions-only) is a different story. It restricts actions like printing or copying, but because the file can still be opened, the data is technically accessible. Several freely available tools can remove owner-password restrictions without knowing the password. This is why meldpdf sets a user password — it is the only kind that provides real security.
  • Once someone has the password, they can remove it and redistribute the unprotected file. Encryption controls access, not redistribution.
What happens if I forget the password?

The file is permanently locked. There is no backdoor, no recovery option, and no way for meldpdf or anyone else to open it. This is by design — if the password could be recovered, the encryption would be meaningless. Always store your password in a password manager or other secure place.

Can I password-protect a PDF on my phone?

Yes. This tool runs in any modern browser, including on iOS and Android. The encryption engine downloads once and works the same way as on a desktop computer.
