How to split a PDF and extract pages

Pull out a single page or a range of pages from any PDF and save them as a new file.

🔒 Pages are extracted in your browser — your PDF is never uploaded.

Step by step

  1. Open the Split / Extract tool and add your PDF.
  2. Type the pages you want in the box — for example 1-3, 5, 8-10. Use hyphens for ranges and commas to separate.
  3. Click Extract pages. A new PDF containing only those pages downloads as extracted.pdf.

Understanding page ranges

The page box accepts any mix of single pages and ranges. 2 extracts just page two. 1-4 extracts the first four pages. 1-3, 7, 10-12 extracts pages 1, 2, 3, 7, 10, 11 and 12 in order. Pages outside the document are ignored, so you never get an error for over-shooting the last page.

When splitting a PDF helps

  • Sending someone only the pages they need instead of a 60-page report.
  • Separating a signed contract page from a longer agreement.
  • Breaking a scanned booklet into individual documents.
  • Removing confidential pages before sharing.

Frequently asked questions

Can I split a password-protected PDF?

You'll need to remove the password in your PDF reader first, because an encrypted file can't be read for extraction.

Does the original file change?

No. Your original stays untouched on your device; the tool creates a brand-new PDF with the pages you chose.

Are my pages uploaded anywhere?

Never. Extraction happens locally in your browser. See the privacy policy.

Split vs Delete — which tool to use

Splitting and deleting are two sides of the same coin. The split / extract tool asks you to list the pages you want to keep; the delete pages tool asks you to list the pages you want to remove. Choose whichever list is shorter. If you need pages 1-3 out of a 50-page report, splitting is faster — you type 1-3. If you need everything except page 12, deleting is quicker — you type 12. Both tools produce a brand-new PDF and leave your original untouched.

Tips for splitting large documents

  • Know your page numbers. Open the PDF in any viewer and note which pages you need before switching to the split tool. This avoids trial and error.
  • Use ranges liberally. Typing 1-25 is faster than listing 25 individual pages. Mix ranges and singles freely: 1-10, 15, 20-30.
  • Split in stages if needed. For a 500-page document where you need three separate excerpts, run the tool three times with different page ranges. Each run is instant.
  • Check the page count. After downloading, open the extracted file and confirm the number of pages matches what you expected. It is easy to mistype a range.

What stays and what is lost when you split

When you extract pages from a PDF, the new file contains exact copies of those pages — text, images, vector graphics, and annotations all come through unchanged. Here is what to be aware of:

  • Bookmarks. The document outline (bookmarks panel) is not carried into the extracted file. If the original had a clickable table of contents, the new file will not.
  • Internal links. A hyperlink on page 3 that pointed to page 40 will break if page 40 is not part of the extraction. External links (URLs) are preserved.
  • Form fields. Interactive form fields on extracted pages are kept, along with any data already filled in.
  • Embedded fonts. Fonts used on the extracted pages are included in the new file, so text renders correctly even on devices that do not have those fonts installed.
  • File size. The extracted PDF is usually proportional in size to the number of pages you pulled. Shared resources like fonts may be duplicated, so a 10-page extract from a 100-page file might be slightly more than one-tenth the size.
Can I split a PDF into individual pages automatically?

The tool is designed for extracting a specific range. To split every page into its own file, you would run the extraction once per page — type 1, download, then 2, download, and so on. For documents with many pages this is tedious; a command-line tool like pdftk or qpdf can automate single-page splitting if you need it regularly.

Does splitting preserve the original page size and orientation?

Yes. Each page keeps its original dimensions and rotation. If the source PDF mixes A4 and Letter pages, the extracted file will too.
