About meldpdf

meldpdf is an independent, privacy-first set of PDF tools that runs entirely in your web browser. There's no sign-up, no watermark, and — for everything the browser can do locally — no upload.

What meldpdf does

It's a single free toolkit for the everyday PDF jobs people actually need: compress, merge, split, delete and reorder pages, rotate, convert to and from images, add page numbers or a watermark, sign, extract text, convert to Word, view and remove metadata, OCR a scan, and password-protect or unlock a file. Each tool has its own page so you can go straight to the task.

How it works

meldpdf processes your files on your device using open-source libraries that run inside the browser — pdf-lib and PDF.js for the PDF work, plus tesseract.js for OCR and a WebAssembly build of qpdf for password protection. Because the work happens locally, your document's contents are never sent to a server. The full, honest details are on the PDF privacy page.

Principles

  • Privacy by design. If a job can be done in the browser, it is — so your file stays with you.
  • Honest about limits. Where a tool has trade-offs (image-based compression, text-only Word export, engine downloads for OCR and encryption), we say so plainly.
  • No dark patterns. No forced accounts, no watermarks, no crippled free tier.
  • Open where it counts. The site's code is public on GitHub.

Who makes it

meldpdf is built and maintained by an independent developer, not a large company. It's a focused side project with a clear goal: the simplest, most private way to handle a PDF. Questions, bug reports and suggestions are welcome — see the contact page.
